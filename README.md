# bener-in
bener.in adalah platform web yang mempertemukan pemilik barang rusak dengan mitra reparasi, memungkinkan pengguna mengajukan Repair Request, memantau status perbaikan, dan melihat dampak barang yang berhasil diselamatkan dari sampah. Dibangun dengan Django untuk mendukung gaya hidup sustainable living melalui prinsip "repair before replace".
